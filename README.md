# Yuvraj Singh — QA Automation Portfolio

## Run locally
1. Open `index.html` in Chrome/Edge/Firefox.
2. No server, framework, or installation is required.

## Customize
Search in `index.html` for:
- `your.email@example.com` → your email
- LinkedIn URL → your profile
- GitHub URL → your repository/profile
- Project cards → your real project links/details

## Suggested deployment
Upload the folder to GitHub Pages, Netlify, or Vercel.
